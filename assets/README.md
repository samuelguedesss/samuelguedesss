# Artes do perfil

Layout inspirado no perfil de [eduardo-toste](https://github.com/eduardo-toste), com arte e gerador próprios, os dados de Samuel Guedes e paleta preta/cobre do portfólio.

- `avi-ascii.svg`: retrato a partir do avatar público de Samuel.
- `info-card.svg`: informações em estilo fastfetch.
- `contrib-heatmap.svg`: contribuições reais em tons de cobre.

Gerar: `python3 scripts/build_profile.py`. Atualizar dados públicos: acrescentar `--refresh`.
